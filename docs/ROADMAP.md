# Roadmap

Roughly in order. Open an issue to discuss before starting a big one.

1. **Phone notifications.** Web push through a small Supabase Edge Function, respecting each member's weekly limit and quiet hours. (iPhone users need the app on their Home Screen.)
2. **Leagues.** Weekly groups of about 30 with promotion and demotion, ranked by quests finished.
3. **Captain scope.** Captains write quests only for their own guild; guildmasters approve national ones.
4. **More languages.** Chinese, Vietnamese, Tagalog, Korean, Arabic, Haitian Creole, and for Minnesota, Somali and Hmong. Member screens first, then a translator role in the composer.
5. **Bluesky check-ins.** Bluesky's open API can show public like and repost counts on a quest's target post, as a second signal next to the honor system.
6. **Scout inbox.** Members send Rangers' reports from the app; organizers turn them into quests in one tap.
7. **CAPTCHA on join** and an accessibility audit before a public launch.
8. **Automated tests** for the SQL functions and the demo backend.
